ZONA — иконки 220 предметов
Папка содержит 220 индивидуальных WebP (каждый назван ID предмета), JSON-карту icon-manifest.json и этот README.
Не переименовывайте картинки: index.html обращается к ним по имени ID.
200 первичных изображений подготовлены из 10 исходных пользовательских листов, 19 визуально переработаны из них, 1 дополнительный ключ нарисован отдельно.
Для добавления новых предметов: создайте <новый_id>.webp, добавьте в константу images в скрипте individual-item-icons внутри index.html и создайте предмет в DB.items.
